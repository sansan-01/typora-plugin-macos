# Typora Mac 功能验收表

核对日期为 2026-11-12。核对环境为 Apple 芯片 Mac、Typora 1.14.15，插件装在原来的 Typora 应用中。功能范围以 [上游 GitHub 插件清单](https://github.com/obgnail/typora_plugin#plugin-list) 为准，另列 Mac 新增功能和你提出的调整。

## 总览

| 状态 | 上游模块数 | 判定依据 |
| --- | ---: | --- |
| 已验证 | 18 | 有主流程或表内所列操作的实机验证记录。各行注明剩余测试和已知差异。 |
| 已接入，待验 | 47 | 安装包中有模块，全开测试曾初始化。部分已有界面或独立测试证据，主要操作仍待实机验收。 |
| 功能有缺口 | 2 | 一键升级和跨平台文章发布存在明确的 Mac 实现缺口。 |

本次逐项匹配了上游清单、项目源码和已安装插件，并逐文件核对了项目插件目录与安装包内的对应文件。67 个模块全部匹配。历史全开测试日志记录了 67 个模块初始化，当前安装的最近启动日志记录了 47 个。本表用此前实机记录、现有导出产物和本次源码与日志核对判定状态。

## 重点需求和已知差异

| 功能 | 状态 | 验收结果 |
| --- | --- | --- |
| 从原 Typora 图标直接打开 | 已验证 | 原应用能启动插件服务，Finder 和 Dock 使用原应用入口。 |
| 原生右键整合 | 已验证 | 普通右键同时显示剪切、拷贝、粘贴和视觉、编辑、组件、交互四组，模糊模式能从原生菜单执行。 |
| 常用／少用插件两组 | 未做 | 当前上游清单配套的默认设置和本机安装都使用四组分类。上游配置可自定义组名和列表；你提到的两组未配置。 |
| 原生右键的插件快捷键标注、只显示插件、子菜单外观选项 | 未做 | 原生菜单未读取快捷键与命令图标字段，也未应用上游的只显示插件及子菜单宽度设置。 |
| 模糊模式 | 已验证 | 原生菜单启用已通过，切换段落与还原有 WebKit 测试记录。 |
| 标题大纲生成思维导图 | 已验证 | Markmap 弹窗从文档标题生成。写回文档的 Mermaid 树图与关系图仍待实机验收。 |
| Carbon 仅代码块右键可见 | 已验证 | 原生菜单在代码块显示 Carbon、PNG、SVG、主题、字体；正文不显示 Carbon。 |
| Carbon 导出与暂存 | 已验证 | 原生子菜单已实测导出 SVG，并核对生成文件。PNG 有此前实际导出文件，整合后的原生 PNG 入口待复测。输出位于插件的 user_space/carbon-temp。 |
| Carbon 主题与本机字体 | 已验证部分 | 已接入 29 套主题和本机字体，既有 SVG 产物使用 Dracula 与 Courier New。整合后的原生菜单选主题及字体弹窗待复测。 |
| 右上角 Typora 自带图标左移 | 未做 | 绿色 Markdownlint 状态灯已在本机配置关闭；字数、大纲等原生控件的位置尚未调整。 |
| 一键升级并自动重启 | 未做 | 已支持检查更新与暂存。目前须退出 Typora 后重跑安装脚本。 |
| WordPress、博客园、CSDN 发布 | 未做 | 平台代码已保留，所需运行依赖未接入 Mac。 |
| Mac 兼容范围 | 待验证 | 实机记录覆盖 Apple 芯片和 Typora 1.14.15。Intel Mac、其他 Typora 版本、原生菜单跨窗口行为未验收。 |
