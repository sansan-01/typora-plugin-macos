# Typora 插件 Windows 与 macOS 对照

2026-11-11 核对。上游 Windows/Linux 清单和 GitHub 默认分支提交为 `7b3b7918aee89f7d823c3a01aa426e3b05e2bc93`。Mac 端为 Apple 芯片、Typora 1.14.15，插件装在原来的 `/Applications/Typora.app` 内。[上游清单及 Windows 安装说明](https://github.com/obgnail/typora_plugin#plugin-list)

上游清单的 **67 个用户插件模块全部保留**，另有 1 个内部测试模块。原应用本次日志显示 47 个插件载入。此前在全部启用的测试环境中，67 个用户插件都完成了载入。载入仅证明插件通过初始化，实际操作和导出结果见下表。

## 关键差异与修复

| Windows 上游功能 | 当前 Mac 版 |
| --- | --- |
| 在普通右键菜单中直接展开插件分组 | Mac 正文普通右键在 Typora 原生菜单内显示视觉、编辑、组件、交互四组，已实测展开并执行插件。代码块右键同时提供 Carbon 和复制代码。 |
| 标签页在文件或文件夹重命名后自动跟随路径 | 已接入 Typora 的文件路径通知和文件树改名事件。原应用实际改名成功，独立测试验证标签路径和目录子路径同步、另存为保留原标签。多窗口标签栏同步仍待实测。 |
| Windows 的 CMD、PowerShell、Git Bash、WSL 运行入口 | Mac Commander 使用 Bash、SH、Zsh。已在 Typora 面板执行脚本并看到中文输出，独立测试通过脚本输入、标准错误、取消及超时。 |
| 通过插件运行 Ripgrep 全文搜索 | 已接入系统 Ripgrep 或 VS Code 自带的 Ripgrep。已安装服务实际找到二进制并搜出测试文档中的中文，面板交互仍待验。Ripgrep 默认关闭。 |
| 一键更新并重启应用更新插件 | Mac 可联网检查和暂存合并，新版本要退出 Typora 后重跑安装脚本。真实上游新版本应用还待验证。 |
| 发布文章到 WordPress、博客园、CSDN | WordPress 和博客园依赖 Selenium 和 ChromeDriver，目前缺少 Mac 运行接入。CSDN 路径也缺少运行所需的 `marked` 模块接入。三站均未实测发布。 |

截图里的字数、大纲和侧栏按钮是 Typora 的原生标题栏控件，位置由应用自身约束控制。当前 Mac 版已经在你的配置里关闭遮住按钮的 Markdownlint 状态灯，标题栏控件本身的左移未实现。

## Mac 新增

代码块右键的「Carbon」子菜单提供 PNG、SVG、29 套官方主题和本机字体选择。图片写入插件数据目录下的 `user_space/carbon-temp`，再请求 Finder 显示图片。已在原 Typora 导出 PNG 和 SVG，并核对 SVG 使用了 Dracula 和本机 Courier New。
